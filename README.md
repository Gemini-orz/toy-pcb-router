# toy-pcb-router
玩具规模的格子图走线实验：小模型 vs A*。A toy-scale grid routing experiment: a small learned model vs. A*.

**状态：刚建仓库，只有计划，还没有任何代码和结果。**

## 打算做什么
在一张十几格见方的格子图（假的小电路板）上，把成对的引脚连起来：

1. 随机生成板子，写一个"裁判"判断连没连通、有没有违规。
2. 用传统找路算法 A* 走线，当作老师和及格线。
3. 训练一个小卷积网络模仿老师，看它能学到几成。
4. 把两者并排对比，做一个能在浏览器里点着玩的演示页。

## 先说清楚
- 这是玩具规模，走不了真实的电路板。
- 板子全部由程序随机生成，不含任何真实设计数据。
